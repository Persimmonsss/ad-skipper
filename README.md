# ad-skipper

Android 免 root 广告跳过工具（无障碍服务实现）。

## 已有模块

### B 站时间轴内嵌广告跳过（实测通过）

- 数据来源：社区库 SponsorBlock 镜像（`bsbsb.top`），只使用 `sponsor` 分类
- 视频识别：优先取媒体会话标题 → App 内搜索 → aid → BV 号（`AvBv.kt` 本地换算）；
  整句标题搜索易命中无关视频，改取首分句 + 标题/时长打分，失败自动重试 2 次
- 进度读取：详情页内联播放器的 MediaSession 不更新 PlaybackState，改读播放器无障碍节点
  （`gemini_halfscreen_progress_text`）并在控件隐藏时按时间外推
- 跳转：优先 `MediaController.transportControls.seekTo()`（会话 actions 含 SEEK_TO，
  实测生效且精确），失败退回拖动进度条
- 跳过前 3 秒在底部弹出气泡倒计时（`3 秒后跳过广告`），可在设置里关闭倒计时
- 跳过成功后气泡变为 `已跳过广告 撤回`，3 秒内点“撤回”可回到广告前 2 秒（防误跳），
  撤回后该广告段本视频内不再自动跳过；关闭倒计时不影响这个撤回入口
- 广告前的跳过判断以真实进度为准，一次广告只跳一次；跳过结果用会话/界面读数双重校验

实测样例：BV1e1HA6RE1u，广告段 09:21.8–10:43.4，跳过落点 10:43.5，倒计时 3-2-1 可见。

### 开屏广告跳过（启发式）

- 监控前台应用切换，在前若干秒扫描 `跳过/关闭/跳过广告` 等文案与常见 id
- 激进口味：看到可点击的跳过控件就点；带冷却与次数上限，避免误点
- 无目标应用白名单时对所有 App 生效
- 纯图片开屏（无任何文字节点）兜底点右上角，但不作用于 B 站，避免视频页刚加载时误触

### 红果短剧广告跳过（v1.3.0）

- 目标包名：`com.phoenix.read`、`com.phoenix.read.tv`、`cn.xiaochuankeji.zhibo`
- 文字关键词 + 倒计时 + 广告 SDK 控件三重检测
- 命中广告后自动上滑进入下一段内容，并统计成功/失败
- 只在红果处于前台时轮询（省电）；检测用正则已预编译，2 秒一轮不产生额外对象

### 统一入口

- MainActivity 仪表盘：三项权限状态（无障碍 / 通知使用权 / 悬浮窗）、四个开关、实时统计与日志

### 省电策略

- 息屏时不读取无障碍节点（`PowerManager.isInteractive` 门控）
- B 站 1 秒定时器只在 B 站处于前台时运行，切到别的 App 立即停掉
- 视频没有广告段时，界面扫描从 300ms 一次降到 1 秒一次
- 红果只在红果前台时 2 秒轮询一次；开屏检测只在 App 切换后的 10 秒窗口内进行
- 检测用正则全部预编译，轮询不额外分配正则对象

## 构建

```bash
# 需要 JDK 17 + Android SDK；工程路径含中文时请复制到纯 ASCII 目录再构建
./gradlew assembleDebug
```

设备上需开启：无障碍服务、通知使用权（B 站标题识别）、悬浮窗权限（倒计时气泡）。
