# T5 · MIUI 常驻与省电设置清单（K40 / 小米红米）

> 负责人：豆包QA｜目的：让用户（或任何装机的人）一次性把四个权限 + 两个 MIUI 专属项配好，避免"权限都开了但就是不跳"。
> 对应 README §安装与权限、§省电策略。此清单供 README 与 App 引导文案统一口径。

## 设置清单（按顺序）

| # | 设置项 | 路径 | 为什么必需 | 确认生效的方法 |
|---|---|---|---|---|
| 1 | 无障碍服务 | 设置 → 更多设置 → 无障碍 → 跳广告工具 | 读屏幕文本、模拟拖动/点击全靠它 | 设置页该项显示「已开启」；App 仪表盘第一行绿 |
| 2 | 通知使用权 | 设置 → 通知与控制中心 → 通知使用权 → 跳广告工具 | 读 B站 播放会话标题/进度，定位视频 | 仪表盘第二行绿；切视频时 App 日志出现「解析视频：…」 |
| 3 | 悬浮窗 | 设置 → 应用 → 跳广告工具 → 悬浮窗/显示在其他应用上层 | 显示「3 秒后跳过 / 撤回」气泡 | 播放到广告段前 3 秒屏幕出现气泡 |
| 4 | 电池优化（无限制） | 设置 → 应用 → 跳广告工具 → 省电策略 → 无限制 | **MIUI 不加白名单会把后台服务冻结**：通知监听被拒绑定，表现为"权限都开了但就是不跳" | 仪表盘「电池优化」行显示已加白名单 |
| 5 | 自启动 | 设置 → 应用 → 跳广告工具 → 自启动 → 允许 | MIUI 允许自启动，服务被杀后能自动拉起 | 设置页显示允许；重启手机后 App 服务自动恢复 |

## MIUI 专属坑（K40 实测）

1. **覆盖安装/系统升级后悬浮窗权限会被重置**：重装包后回设置重新开一次悬浮窗。
2. **省电冻结的表现**：权限全开但跳过失效 → 先查第 4、5 项。
3. **重启手机后**：确认无障碍服务仍开启（MIUI 偶发自动关闭第三方无障碍服务）。

## 服务僵死态的恢复路径（已知未修，README 需写明）

现象：无障碍显示已开启、通知显示已开启，但 App 无响应/不跳。
恢复：
1. 设置 → 应用 → 跳广告工具 → 强行停止；
2. 重新打开 App（服务重新绑定）；
3. 如果仍不跳，关闭再打开无障碍与通知使用权各一次。
（根因：服务进程与系统绑定状态不同步，force-stop 重开即可恢复。）
